# Release 0.6.0 validation

- Lint, TypeScript and 85 unit tests in 14 files passed.
- Windows UI/main/native production build and directory packaging passed.
- All three multilingual Q5_1 models match the pinned upstream file sizes/SHA-256 values. Packaged native preset buttons selected each model without a download; all transcribed the artificial English fixture. Offline restart retained the chosen model.
- The isolated installer test verified rejection of an unrelated nonempty folder, installation of an older 0.5.4 fixture, refusal to upgrade/uninstall while that target was running, successful 0.6.0 upgrade after fixture Quit, all 115 installed payload files matching the build, preference preservation, offline presence of all three models, reinstall and uninstall. Uninstall removed the known app executable and retained an unrelated extra file and the external artificial user-data sentinel.
- The installer validation variant used the same NSIS script/payload/guard with a separate product/registry namespace. The actual user's active app and data were never uninstalled. The first harness run quoted NSIS's final `/D` argument incorrectly; its accidental validation install was identified and removed without launching it. The corrected final checks used fresh explicit fixture folders. Canonical paths are used by the guard to account for aliases/virtualized filesystem paths.
- Packaged answer-first regression passed: native provider picker, streaming, independent failure/answer cards, new-speech cancellation, repeated completion and offline model preference persistence. All requests were mocked, and recording endpoints stayed off.
- The complete public documentation and installed payload were audited for private files/data, source-path leakage and credential patterns. Runtime files/model files are compared with verified upstream/build artifacts; compiled archive contents are bounded. Published assets are checksum-verified against remote release metadata.

These are release acceptance checks, not hardware certification or a live meeting trial. No real microphone/system recording, provider inference, new OAuth grant or real screen transmission occurred. Windows 10/ARM64, other CPU/device combinations, every share mode and complete live OAuth/provider interoperability remain unverified. No signing certificate was purchased; the installer is unsigned.

Corresponding third-party source downloads accompany the release: exact Chromium FFmpeg revision `2b68d2babae73714846961fb0ee47e3b3d2e39a9` and Electron `44.5.1` source/patch archive. The full notices remain installed and publicly available. The public repo begins with a clean documentation commit; private application history, raw diagnostic evidence and user account/session data are not included.
